# Командное решение

Собственный solver, его тесты и документация будут находиться здесь. Реализация пока не начата: сначала команда изучает [технический анализ](../ANALYSIS.md) и согласует план.

Входной пакет остаётся в корне репозитория под исходными путями `targets/`, `skeleton/`, `scenarios/`, `context/`, `gold/`, `platform/` и `examples/`. Код решения должен читать эти каталоги как внешние входы; не копируйте данные внутрь `solution/`.

Для временных ответов и диагностик используйте `solution/output/` (игнорируется Git). Финальные артефакты и код для сдачи добавляйте осознанно отдельным коммитом.
