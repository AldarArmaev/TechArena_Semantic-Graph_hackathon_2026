# Совместная работа

Этот репозиторий содержит исходный пакет задачи TechArena и будущий командный solver. Корневые пути исходного пакета сохранены: документация, baseline-команды и проверка используют их напрямую.

| Путь | Назначение |
| --- | --- |
| `README.md`, `REFERENCE.md` | Условия и правила соревнования |
| `ANALYSIS.md` | Исследование задачи и план реализации; solver пока не написан |
| `targets/trainticket/`, `skeleton/`, `scenarios/`, `context/`, `gold/` | Входные исходники и данные конкурса |
| `platform/`, `examples/` | Штатные baseline, проверка и примеры ответов |
| `solution/` | Место для собственного кода, тестов и инструкций команды |

Работайте в отдельных ветках от `main` и объединяйте изменения через pull request. Не меняйте эталонные входные данные без отдельного обсуждения: изменение этих файлов затруднит сравнение результатов команды. Генерируемые файлы складывайте в `solution/output/`; каталог исключён из Git. Не добавляйте `.env`, пароли, токены и другие локальные секреты.

Сначала прочитайте `README.md`, `REFERENCE.md` и `ANALYSIS.md`. В рамках конкурса разрешён статический анализ и компиляция исходников, но запрещён запуск Train Ticket, его сервисов и сбор runtime traces. Для локальной проверки ответов используйте `platform/evaluate_golden.py` и открытый `gold/S0.json`; S0 не входит в итоговую оценку.
